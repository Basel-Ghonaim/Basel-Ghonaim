## 🧠 About Me

I'm a frontend engineer based in Gaza City, Palestine, focused on building scalable, well-architected web applications with React and TypeScript. I care about clean architecture and long-term maintainability as much as I care about shipping — and I use AI tooling deliberately to move faster without cutting corners.
