## 🧠 About Me

I'm a frontend engineer based in Gaza City, Palestine, focused on building scalable, well-architected web applications with React and TypeScript. I care about clean architecture and long-term maintainability as much as I care about shipping — and I use AI tooling deliberately to move faster without cutting corners. I'm currently expanding into backend engineering to grow into a full-stack role.

<br/>

> 🎯 **My engineering philosophy:** _Code is a liability — architecture is an asset._
> I don't just write features; I design systems that are **readable**, **scalable**, and **maintainable** long after the first commit.
